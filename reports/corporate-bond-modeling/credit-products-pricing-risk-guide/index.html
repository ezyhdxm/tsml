0. Scope：public-only 教程

本文只讨论公开、通用的市场结构与数学框架，不包含任何公司的人员、项目、内部系统、模型编号、生产配置或非公开数据。主线是：合同现金流 → 风险中性定价 → 市场校准 → Greeks / scenario risk → hedge → residual risk → FRTB 映射。

边界：公式是产品经济结构和常见建模骨架，不代表任何机构的特定 pricer。生产级估值仍需精确处理 day-count、accrual-on-default、coupon conventions、stubs、settlement、holiday calendars、default states、collateral 与 curve construction。

1. 共通定价地基

绝大多数信用产品都可以抽象成风险中性期望：

\[V_0=\mathbb E^{\mathbb Q}\left[\sum_k D(0,t_k)CF_k(X_{t_k})\right].\]

产品之间的差异主要在 cashflow function 与 state variables：CDS 依赖 survival/default；CDX 再加入 constituents 和 index factor；option 加 volatility 与 nonlinear payoff；tranche 加 portfolio-loss distribution；TRS 加 financing leg；ETF 加 holdings 和 creation/redemption；callable bond 加 issuer exercise。

Curve risk

discount curve、forward curve、credit spread / hazard curve，对应 DV01、CS01、key-rate risk。

Jump / nonlinear risk

default jump、option gamma/curvature、tranche threshold effect，不能只靠一阶 sensitivity。

Model / basis risk

recovery、correlation、prepayment、funding、liquidity、index basis、ETF tracking difference。

2. 重要产品：定价、风险分解与 hedge 推导

每个 tab 都按同一逻辑展开：现金流是什么 → 如何定价 → market quote 如何进入模型 → Greeks 从哪里来 → 怎么 hedge → hedge 后剩什么。

统一记号：\(D(0,t)\) 为 discount factor；\(Q(t)=\mathbb P^{\mathbb Q}(\tau>t)\) 为 survival probability；\(\lambda(t)\) 为 hazard rate；\(R\) 为 recovery；\(N\) 为 notional；\(\alpha_i\) 为 accrual fraction。

CDS：信用产品的基本积木

premium leg 换 default-contingent protection leg。理解 hazard、recovery、RPV01、CS01 和 JTD 后，后续很多信用产品都只是把这些积木做组合或非线性变换。

定价

\[PV_{prot}=N(1-R)\int_0^T D(0,t)\lambda(t)Q(t)dt,\qquad PV_{prem}=sN\sum_i\alpha_iD(0,t_i)Q(t_i)+AoD.\]

par CDS 满足两腿现值相等，因此

\[s_{par}=\frac{(1-R)\int_0^T D(0,t)\lambda(t)Q(t)dt}{RPV01}.\]

如果用 piecewise-constant hazard，可以从短 maturity 到长 maturity 逐段 bootstrap \(\lambda(t)\)。常见近似 \(s\approx\lambda(1-R)\) 只在简化条件下成立。

Risk management

CS01

信用 curve bump 1bp 后的 PV 变化。实际常用 bump-and-revalue：\(CS01\approx V(s+1bp)-V(s)\)。

JTD

真正 default 是离散 jump，不能由连续 spread sensitivity 代替。

Recovery risk

既直接影响 LGD，又影响从 market spreads bootstrap 出来的 hazard curve；是否 rebootstrap 会改变 risk definition。

Bond-CDS hedge

一阶 notional 可按 \(N_{CDS}\approx CS01_{bond}/CS01_{CDS,unit}\) 匹配，但仍有 basis、liquidity、funding 与 default-settlement residual risk。

CDX：一篮子 single-name CDS 的可交易指数

除了 constituent credit risk，还多了 fixed coupon + upfront、series/roll、index factor、default state 和 index-vs-single-name basis。

定价骨架

\[V_{index}\approx N\sum_i w_iV_i.\]

真实 index 有标准 coupon \(c\)。若市场 fair spread \(s^*\neq c\)，upfront 一阶近似为

\[Upfront\approx (s^*-c)\,RPV01_{index}\,N.\]

发生 constituent default 后，surviving index factor 改变未来 premium base，因此 settled/unsettled 状态也会影响 PV 与后续衍生品。

Risk

  • Index spread risk：同 series/tenor CDX 是最直接 hedge。
  • Dispersion / basis：index 不动时个别 names 仍可大幅变化。
  • Default / factor：default 既产生 loss jump 又改变 surviving notional。
  • Roll risk：on-the-run 与 off-the-run series 在成分和流动性上不同。

并且一般不能把 index parallel CS01 简单按 notional weights 当成精确 constituent CS01。

CDX Option：spread risk 之外，Gamma、Vega、FEP 都成为主角

Payer option 通常受益于 spreads widening；receiver 相反。最有用的起点是 Black-style spread option。

\[V_{payer}=A[F\Phi(d_1)-K\Phi(d_2)],\qquad d_{1,2}=\frac{\ln(F/K)\pm\tfrac12\sigma^2T}{\sigma\sqrt T}.\]

Greeks

\[\Delta_F=A\Phi(d_1),\qquad \Gamma_F=\frac{A\phi(d_1)}{F\sigma\sqrt T},\qquad Vega=AF\phi(d_1)\sqrt T.\]

ATM 附近 \(\phi(d_1)\) 较大，因此 gamma/vega 通常最显著。expiry 前 constituent default 还会引入 front-end protection：

\[V_{option}=V_{surviving\ index\ option}+PV(FEP/default\ adjustment).\]

为什么 constituent curvature 不等于 index curvature 按权重拆

若 \(V=f(s_1,\dots,s_m)\)、index spread \(S=g(s_1,\dots,s_m)\)，一般

\[\frac{\partial^2V}{\partial s_i^2}\neq w_i\frac{\partial^2V}{\partial S^2},\]

因为还有 chain-rule square terms、cross-gamma、annuity 与 default-state effects。风险管理通常同时看 index delta、vol surface、gamma、single-name dispersion 和 realized defaults。

CDX Tranche：定价对象是 portfolio loss distribution

attachment \(A\) 和 detachment \(D\) 只让 tranche 承担组合损失的一段。

Loss function

\[\ell_{A,D}(L_t)=\min\{\max(L_t-A,0),D-A\},\qquad TL_t=\frac{\ell_{A,D}(L_t)}{D-A}.\]

premium leg 对尚未损失掉的 tranche notional 支付，protection leg 对 tranche expected loss 的增加支付：

\[PV_{prem}=sN_{tr}\sum_i\alpha_iD_i\,\mathbb E[1-TL_{t_i}],\qquad PV_{prot}=N_{tr}\int_0^T D(0,t)d\mathbb E[TL_t].\]

Correlation 为什么核心

在一因子 Gaussian copula 直觉里，name defaults 通过共同因子相关。higher correlation 往往把 loss distribution 推向更厚的两端，因此不同 attachment/detachment tranche 的影响方向和大小不同；这也是 base correlation / correlation skew 存在的原因。

Risk

  • index spread / hazard；
  • correlation / base correlation；
  • recovery；
  • name concentration 与 JTD；
  • tranche roll、liquidity 和 model risk。

Bond / Loan TRS：交换 underlying total return 与 financing leg

经济上接近“合成持有 underlying + 融资”，但真正的定价关键在完整生命周期与 financing reset。

现金流

对 payer of total return 的反方来说，一个 period 的 reference-leg cashflow 可写成

\[CF_i^{TR}=q[P_i-P_{i-1}+Coupon_i+Principal_i+Recovery_i].\]

financing leg 常类似 \(qN_i(L_i+m)\alpha_i\)。若初始 PV 设为 0，fair margin \(m^*\) 满足

\[m^*=\frac{PV(total\ return\ leg)-PV(reference\ floating\ leg)}{A_{fund}},\qquad A_{fund}=\sum_iD_i\alpha_iN_i.\]

Risk decomposition

DV01

underlying bond/loan 与 financing leg 都暴露于 rates，但方向和 duration 不同。

CS01

underlying credit spread widening 会改变 total-return leg PV。

Default / recovery

default 会同时影响 reference price、recovery cashflow 和 remaining notional。

Funding / basis

financing index、funding curve、liquidity 与 bond spread 之间存在 basis。

loan TRS 还必须处理 amortization/prepayment；双边 TRS 另有 collateral、close-out、CVA/FVA 等 XVA 风险。

Bond ETF：交易像股票，风险本质是债券组合

ETF 有两层价格：fund NAV 与交易所 market price；对 fixed-income risk management 还需要第三层：把总风险分回 constituents。

NAV 与 creation/redemption

\[NAV_t=\frac{\sum_i q_iP_i+Cash-Liabilities}{Shares\ outstanding}.\]

Authorized Participants 通过 creation/redemption 把 ETF 与 basket 连接，使较大的 price-NAV deviation 产生套利压力，但 bond ETF 的 underlying 流动性和 stale marks 会让 basis 暂时存在。

Constituent risk

\[dNAV\approx \frac1{Shares}\sum_i q_i\,dP_i.\]

如果 \(dP_i\approx -DV01_i\,dy_i-CS01_i\,ds_i\)，就得到 ETF 对 rates 与 credit 的 look-through exposure。实际困难包括 non-trading constituents、bid/ask、sampling basket、sector/issuer concentration 和 tracking difference。

Risk

  • rates / credit beta；
  • ETF-NAV basis；
  • underlying liquidity / stale valuation；
  • creation basket 与 full portfolio mismatch；
  • tracking and rebalance risk。

CRT / SRT：保留资产但转移一段组合信用损失

Credit Risk Transfer / Synthetic Risk Transfer 常把 loan portfolio 的某一 loss tranche 转给 protection seller / investors，基础贷款并不一定出售。

定价骨架

把 reference portfolio cumulative loss 记为 \(L_t\)，tranche loss 仍可用 attachment/detachment function 表示。premium leg 对 outstanding protected notional 支付；protection leg 对 tranche loss 增量支付：

\[PV_{prem}=s\sum_iD_i\alpha_i\,\mathbb E[N^{prot}_{t_i}],\qquad PV_{prot}=\int_0^T D(0,t)d\mathbb E[Loss^{tranche}_t].\]

fair premium 满足两腿相等。若 pool 会 amortize/prepay，则 protected notional 与 WAL 都变，spread 也会改变。

Risk

  • PD / hazard deterioration；
  • default correlation 与 concentration；
  • recovery / LGD；
  • amortization 与 prepayment；
  • proxy hedge basis，因为 loan pool 往往没有完美可交易 hedge；
  • legal/structural 与 regulatory-recognition risk。

ABX / CMBX：securitization credit risk 的可交易指数

ABX 参考 RMBS tranches，CMBX 参考 CMBS tranches。它们不能简单当成 corporate CDX，因为 underlying cashflows 还受 prepayment、writedown、interest shortfall、extension 与 waterfall 影响。

统一 cashflow 视角

\[PV_{prot}=\mathbb E\left[\sum_kD(0,\tau_k)LossEvent_k\right],\qquad PV_{prem}=s\sum_i\alpha_iD_i\mathbb E[N^{eff}_{t_i}].\]

因此 par spread 仍可理解为 protection PV / risky annuity，但 \(LossEvent\) 与 effective notional 的定义比 corporate CDS 复杂得多。

为什么 prepayment 也进 credit pricing

mortgage principal 提前归还会改变 WAL、subordination 与 future loss absorption；同样的 credit assumptions 在不同 prepayment/extension path 下可产生不同 fair value。

Risk

  • credit / collateral quality；
  • prepayment / extension；
  • loss severity；
  • waterfall / subordination；
  • index-cash basis 与流动性；
  • risk-factor representation / regulatory mapping。

Callable / Sinkable Bond：现金流会随状态改变

callable bond 含 issuer call option；sinkable bond 的 principal 按 schedule 分期下降，甚至还可能带额外 optionality。

Callable bond

\[P_{callable}=P_{straight}-V_{issuer\ call}.\]

利率下行时 straight bond 上涨，但 issuer call option 更值钱，从而压低 bond upside，造成低 convexity 甚至局部 negative convexity。

利率树 / term-structure model 中，先计算 continuation value：

\[V_t^{cont}=D_t\,\mathbb E_t[V_{t+\Delta t}+CF_{t+\Delta t}],\qquad V_t=\min\{V_t^{cont},CallPrice_t+Accrued_t\}.\]

调 OAS 使模型价格等于市场 dirty price。风险包括 rate duration、rate vol vega、credit/OAS、exercise behavior/model risk。

Sinkable bond

若 principal schedule 确定：

\[P=\sum_iD_i(Coupon_i+Principal_i).\]

本金更早回收通常降低 duration/CS01，并带来 reinvestment risk；若 sinking mechanism 本身有 issuer discretion，则又会出现 optionality。

3. FRTB SA：经济风险如何映射成监管资本

FRTB（Fundamental Review of the Trading Book）的 Standardised Approach（SA）将市场风险资本拆成 Sensitivities-Based Method（SBM）、Default Risk Charge（DRC）与 Residual Risk Add-On（RRAO）。SBM 再覆盖 delta、vega 与 curvature。

\[K_{SA}=K_{SBM}+K_{DRC}+K_{RRAO}.\]

CSR Delta

对 credit spread risk factor \(x_k\) 计算 \(s_k=\partial V/\partial x_k\)，再乘 prescribed risk weights 并按 obligor/sector/quality/tenor/curve type 的 bucket 与 correlations 聚合。真正困难的是复杂产品如何映射到稳定、可复现的 risk factors。

Curvature

监管 curvature 不是单纯报告二阶导，而是对规定 shock 做 full revaluation，再扣除 delta 已解释的一阶部分：

curvature component ≈ full shocked loss − delta-explained loss

这对 CDX options、callable bonds 等非线性产品尤其重要。

JTD / DRC

连续 spread widening 与真正 default 是两类风险。JTD 捕捉 default 的离散 PV jump；DRC 再根据 gross JTD、允许净额、bucket 与 weights 聚合资本。对 index/index options，constituent look-through 往往是关键。

经济 hedge ≠ 监管映射。前者追求 P&L stability，后者追求可审计、可复现、符合 prescribed buckets 的风险表达；两者相关但不完全相同。
