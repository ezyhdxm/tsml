4. 第一类方法：直接对 observation pairs 平滑

4.1 统一 kernel estimator

给定目标 lag \(\tau\) 和 bandwidth \(h\)，定义

\[w_{ij}(\tau)=K\!\left(\frac{d_{ij}-\tau}{h}\right).\]

最直接的 covariance estimator 是

\[\widehat\gamma_h(\tau)=\frac{\sum_{i<j}w_{ij}(\tau)(X_i-\widehat\mu)(X_j-\widehat\mu)}{\sum_{i<j}w_{ij}(\tau)},\qquad \widehat\rho_h(\tau)=\frac{\widehat\gamma_h(\tau)}{\widehat\gamma(0)}.\]

含义很直接：pair 的实际时间差越接近目标 lag，贡献越大。

4.2 Rectangular kernel：slotting / DCF

取 \(K(u)=\mathbf 1\{|u|\le1\}\)，就得到固定 lag bin 内 pair products 的平均：

\[\widehat\gamma_h(\tau)=\operatorname{average}\{(X_i-\widehat\mu)(X_j-\widehat\mu):|d_{ij}-\tau|\le h\}.\]

Edelson–Krolik DCF 先构造每个 pair 的 unbinned discrete correlation，再按 pairwise lag 分箱，因此不需要时间插值。它容易解释和审计，但 bin 边界不连续，bandwidth 仍决定 bias–variance trade-off。

4.3 Gaussian kernel：fuzzy slotting

取 \(K(u)=e^{-u^2/2}\) 后，目标 lag 邻近的 pairs 平滑贡献。Rehfeld et al. 比较 interpolation、Lomb–Scargle、slotting 与 kernel methods；在其高度 irregular 的模拟里，Gaussian kernel 对 lag-1 ACF 的 RMSE 比 linear interpolation 低约 40%，而 interpolation 会明显高估 persistence time。

重点不是把 40% 当作普遍常数，而是机制：插值生成的伪观测可能主导普通 ACF；pair estimator 只使用真实 observations。

4.4 Bandwidth 是 estimand-resolution 的一部分

小 bandwidth 提高 temporal resolution，但 eligible pairs 少、曲线更噪；大 bandwidth 降低方差，却可能把短时 microstructure decay 与长时 stale-model decay 混在一起。因此至少同时报告 ACF、raw pair count、weight concentration 与 bandwidth sensitivity。

权重集中度可用

\[n_{\text{Kish}}(\tau)=\frac{(\sum w_{ij}(\tau))^2}{\sum w_{ij}(\tau)^2}.\]

它只是 weighting support diagnostic，不是考虑 pair dependence 后的 inferential effective sample size。

4.5 Global normalization 还是 local correlation？

若 residual 已在 series 内标准化，可以估计 weighted product mean：

\[\widehat\rho_{\text{prod}}(\tau)=\frac{\sum w_{ij}z_i z_j}{\sum w_{ij}}.\]

也可以使用逐 lag 的 weighted Pearson normalization：

\[\widehat\rho_{\text{local}}(\tau)=\frac{\sum w_{ij}z_i z_j}{\sqrt{\sum w_{ij}z_i^2}\sqrt{\sum w_{ij}z_j^2}}.\]

后者逐点处于 \([-1,1]\)，但不同 lag 的 endpoint composition 会改变 local scale。两者差异很大时，本身就是 composition 或 heteroskedasticity 警报。

4.6 Equal-width bins 与 equal-population bins

固定时间宽度保留统一 temporal resolution，但远端 lag 可能 pair 很少。ZDCF 使用 equal-population bins 与 Fisher \(z\) transform 改善 sparse uneven light curves 的有限样本表现。代价是不同 lag 位置的 temporal resolution 不同。交易 residual 可把 equal-width kernel 作为主图，把 equal-population bin 作为 robustness check。

4.7 S-ACF 不是“另一个 kernel 名字”

S-ACF 对每个 anchor \(t_i\) 和目标 \(t_i+\tau\) 选择最接近的 observed time，并按 mismatch distance 加权；regular sampling 下退化为标准 ACF。

  • All-pairs kernel：目标 lag 附近所有 pairs 都贡献，交易密集区会产生很多 pairs。
  • S-ACF：每个 anchor 通常只选一个近邻 observation，anchor 的影响更均衡。

因此二者对应不同的 finite-sample averaging scheme。对 bond residual 的 conditional pair persistence，可先用 all-pairs kernel，再做 anchor-balanced/S-ACF sensitivity。

5. 第二类方法：先估计 spectrum，再反变换

连续时间弱平稳过程的 autocovariance 与 spectral density 由 Fourier transform 联系。Scargle 发展了 unevenly spaced data 的 Fourier、autocorrelation 与 cross-correlation 工具；之后也有专门的 irregular spectral estimators。

Spectral route 适合周期性和多尺度频率结构；若 spectrum 被约束为非负，反变换 covariance 更容易满足 positive-semidefinite 要求。但 window、aliasing 与 smoothing 并不简单，交易时点内生和日内非平稳也不会自动消失。对“30 分钟后 residual 还剩多少”这种诊断，time-domain pair estimator 通常更直接。
