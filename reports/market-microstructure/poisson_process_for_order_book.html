Poisson Process：从零开始，到 Order Book Master Equation

一句话：Poisson process 是随机事件到达模型。参数 λ 是每单位时间的平均 event rate；在很短的 dt 内，一次事件的概率约为 λdt。从这一条局部规则可以推出 Poisson count、Exponential waiting time、competing clocks，以及 order-book master equation。

1. 四个对象先分清

对象记号含义
事件计数N(t)[0,t] 内发生几次
第 n 个事件时间Sₙ第 n 次什么时候发生
相邻间隔Xₙ=Sₙ−Sₙ₋₁下一次还要等多久
事件率λ平均每单位时间多少次；不是概率

Homogeneous Poisson process 的 count 满足

N(t)∼Poisson(λt),Pr[N(t)=n]=e−λt(λt)nn!.

因此 E[N(t)]=Var[N(t)]=λt。

2. 最重要的 infinitesimal rule

当 dt→0：

Pr(ΔN=1)=λdt+o(dt),Pr(ΔN=0)=1−λdt+o(dt),Pr(ΔN≥2)=o(dt).

所以 λ 是 rate/hazard；只有乘上一个很短的时间长度后，λdt 才近似是概率。

3. 为什么 count 是 Poisson？

令 pn(t)=Pr[N(t)=n]。要在 t+dt 有 n 个事件，一阶上只有两条路：原来已有 n 个且没有新事件，或者原来有 n−1 个且来一个事件：

pn(t+dt)=pn(t)(1−λdt)+pn−1(t)λdt+o(dt).

于是

pn′(t)=−λpn(t)+λpn−1(t).

从 p0(t)=e−λt 递推，就得到 Poisson PMF。这个“概率流入 − 流出”的思路与 master equation 完全相同。

4. 为什么等待时间是 Exponential？

设 X 是下一事件等待时间。“X>t”等价于“到 t 为止没有事件”，因此

Pr(X>t)=Pr(N(t)=0)=e−λt.

所以

X∼Exp(λ),E[X]=1λ.

Exponential 还满足 memoryless property：

Pr(X>s+t|X>s)=Pr(X>t).

所以 homogeneous Poisson 模型中，“已经很久没有订单”不会让下一瞬间更容易来订单。

5. Independent / stationary increments

不重叠时间段里的 event counts 独立；长度同为 h 的区间有相同分布：

N(t+h)−N(t)∼Poisson(λh).

真实市场常有 intraday seasonality，所以更现实的模型会把 λ 换成 λ(t) 或 state-dependent intensity。

6. Superposition、thinning 与 competing clocks

两个独立 Poisson streams 合并后仍是 Poisson，rate 相加：

PP(λ1)+PP(λ2)=PP(λ1+λ2).

因此 execution rate μ 与 cancellation rate ν 可以合并成 departure rate μ+ν。若独立 waiting times Ti∼Exp(λi)，则

miniTi∼Exp(∑iλi),Pr(i first)=λi∑jλj.

例：λ=5、μ=3、ν=2 events/s，则总 rate=10/s，下一事件平均等待 0.1s，三种事件先发生概率为 0.5、0.3、0.2。

7. 直接接到 order book master equation

令 queue volume 为 V：arrival 让 V→V+1，execution/cancellation 让 V→V−1。在 dt 内列出四条一阶路径：stay at V、从 V−1 arrival、从 V+1 departure、depletion 后 reinjection：

P(V,t+dt)=P(V,t)[1−(λ+μ+ν)dt]+λdtP(V−1,t)+(μ+ν)dtP(V+1,t)+J(t)ρ(V)dt+o(dt).

减去 P(V,t)、除以 dt、令 dt→0：

∂P(V,t)∂t=−(λ+μ+ν)P(V,t)+λP(V−1,t)+(μ+ν)P(V+1,t)+J(t)ρ(V).
核心：master equation 不是凭空出现的微分方程，而是 infinitesimal probability bookkeeping：每个状态的概率变化 = inflow − outflow + source。

8. 为什么忽略“同一个 dt 内两个事件”？

两个独立一阶事件同时出现的概率是 O(dt²)。Master equation 最后除以 dt，所以 O(dt²)/dt→0，只保留零个或一个 event 的一阶项。

9. 最小模拟

import numpy as np
rng = np.random.default_rng(0)
lambda_ = 4.0

gaps = rng.exponential(scale=1/lambda_, size=10)
arrival_times = np.cumsum(gaps)
print(arrival_times)

T = 5.0
N_T = rng.poisson(lambda_ * T)
